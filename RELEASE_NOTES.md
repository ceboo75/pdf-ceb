## PDF Ceb — boîte à outils PDF pour Windows

Téléchargez **PDF-Ceb.exe** ci-dessous puis double-cliquez dessus : il n'y a rien à installer.
Tous les traitements ont lieu sur votre ordinateur ; aucun document n'est envoyé sur Internet.

**Organiser** : fusionner, diviser, supprimer des pages, extraire des pages, organiser (glisser-déposer, rotation, pages vierges, ajout d'autres PDF).
**Optimiser** : compresser (3 niveaux), réparer.
**Convertir** : images → PDF, PDF → images (JPG/PNG), extraction des images.
**Modifier** : éditeur (texte, images, formes, flèches, dessin, surlignage, cache blanc, commentaires), rotation, numérotation, filigrane texte ou image, rognage (souris, marges, automatique), remplissage de formulaires.
**Sécurité** : protéger par mot de passe (AES 256), déverrouiller, signer, caviarder (suppression réelle), comparer deux versions.

Au premier lancement, Windows peut afficher « Windows a protégé votre ordinateur » (l'exécutable n'est pas signé par un éditeur) : cliquez sur **Informations complémentaires** puis **Exécuter quand même**.
